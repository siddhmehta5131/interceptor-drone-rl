## NanoBench - IROS 2026 Dataset Repository
Source:     https://github.com/izzat-ullah/nanobench-iros2026
Paper:      https://arxiv.org/abs/2603.09908
Clone cmd:  git clone https://github.com/izzat-ullah/nanobench-iros2026.git
Contents:   170 Crazyflie 2.1 flight trajectories (~215 CSV files, ~700 MB)
            Benchmark tasks: system identification, control, state estimation

## PyBullet Physics Engine (pip package)
Install:    pip install pybullet
Used for:   Comparing drone physics simulation vs Swift/Robotics-Toolbox

## PX4 Flight Logs (public review database)
Source:     https://review.px4.io
Download:   https://raw.githubusercontent.com/PX4/PX4-Autopilot/main/Tools/px4tracelog/download_logs.py
Used for:   System identification from real PX4 ULG flight logs
